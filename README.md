# 🗺️ Планировщик поездок

Статическое веб-приложение для сборки маршрута поездки: расписание по дням, каталог экскурсий по городам и смета с бюджетом. Работает без сборки, без сервера и без сторонних библиотек — чистый HTML + CSS + JavaScript.

**Играть прямо в браузере:** <https://resolga.github.io/trip-planner/>

---

## Что умеет

- **План по дням.** Выбираете город и даты — приложение разбивает поездку на дни и раскладывает экскурсии по дням.
- **Каталог мест.** Для шести городов (Санкт-Петербург, Москва, Казань, Сочи, Екатеринбург, Нижний Новгород) есть готовый список достопримечательностей с подсказками по времени и выходным.
- **Готовый маршрут.** Кнопка «✨ Маршрут» собирает готовый план поездки — можно сразу посмотреть, как это выглядит.
- **Перенос экскурсий.** Карточку можно перетащить за ручку `⠿` в другой день, не пересоздавая её.
- **Смета.** Общий бюджет, потрачено, остаток, разбивка по категориям и прочие траты (проживание, транспорт, питание, билеты, сувениры).
- **ИИ-помощник.** Необязательный чат с DeepSeek: подсказывает маршрут и отвечает на вопросы по поездке. Ключ вводится в настройках и хранится только в вашем браузере.
- **Голосовой ввод.** Кнопка 🎤 в чате — работает через Web Speech API.
- **Экспорт и импорт.** Скачивание плана в JSON и загрузка обратно.
- **Данные — в вашем браузере.** Планы, смета и траты хранятся в `localStorage` отдельно для каждого города. Ничего никуда не отправляется.

## Как играть

1. Откройте ссылку выше.
2. Введите город и даты поездки, нажмите **«Сохранить»**.
3. Добавьте экскурсии кнопкой **«+ Добавить»** или подставьте готовый маршрут кнопкой **«✨ Маршрут»**.
4. Задайте бюджет в блоке «💰 Смета» и вносите траты.
5. При необходимости перетащите экскурсию в другой день за ручку `⠿`.

## Как запустить локально

Сборка не нужна — приложение полностью статическое. Достаточно любого локального сервера:

```bash
python -m http.server 8000
```

и открыть <http://localhost:8000/>.

> Открывать `index.html` двойным щелчком тоже можно, но локальный сервер лучше: по `https` (как на GitHub Pages) корректно работает голосовой ввод.

## Структура

```
index.html            # разметка: шапка, форма поездки, доска дней, модальные окна
css/styles.css        # всё оформление
js/
  data.js             # справочники: города, каталог мест, готовые маршруты
  utils.js            # вспомогательные функции (даты, деньги, экранирование)
  dom.js              # поиск элементов и мелкие хелперы по DOM
  state.js            # состояние приложения и сохранение в localStorage
  render.js           # отрисовка дней, карточек экскурсий и шапки
  excursion.js        # добавление, редактирование, удаление, перетаскивание
  budget.js           # смета: бюджет, траты, разбивка по категориям
  trip.js             # форма поездки, смена города, импорт и экспорт
  ai.js               # чат с DeepSeek (ключ хранится в браузере)
  speech.js           # голосовой ввод (Web Speech API)
  main.js             # инициализация и связывание модулей
```

Ключ хранения данных — `trip-planner-v4`. Формат сохранённых данных менять нельзя: на нём завязана миграция со старой версии.

## Особенности и ограничения

- **Чат с DeepSeek** ходит напрямую в `api.deepseek.com` из браузера. Если сервис блокирует запросы по CORS, укажите в настройках адрес своего прокси в поле **Base URL**.
- Перетаскивание экскурсий работает на широких экранах (от 640 px). На телефоне перенос делается через форму.
- Данные лежат в `localStorage` браузера — при очистке кэша они пропадут. Пользуйтесь экспортом в JSON, чтобы сохранить план.
